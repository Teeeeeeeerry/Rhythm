# L4 手工烟测清单（唯一人工环节，8 项主观审美项）

> 其余一切自动化（L0 静态 / L1 单元 / L2 快照 / L3 UI）全绿之后，PR 合并前
> 由人眼完成以下 8 项。每项 ≤ 3 分钟。全勾选才允许合并。

执行环境：macOS 与 Windows 各过一遍（双端 token 一致但渲染环境不同）。
勾选即代表该项通过；任一项不通过 → 记到 PR comment 并阻断合并。

## 检查项

| # | 项 | 检查要点 | macOS | Windows |
|---|---|---|---|---|
| 1 | 深色 teal 耐看度 | 无廉价感/荧光感；长时使用不刺眼 | ☐ | ☐ |
| 2 | 4 徽标色和谐度 | 同页混排不打架；均与 teal 家族协调 | ☐ | ☐ |
| 3 | Light 卡片可辨性 | elevated==surface 时卡片靠阴影/边框仍可辨 | ☐ | ☐ |
| 4 | 选中高亮统一 | 15%（侧边栏）vs 12%（曲目行）观感一致 | ☐ | ☐ |
| 5 | 长标题截断 | 超长标题省略号位置合理，无裁字 | ☐ | ☐ |
| 6 | 空状态排版 | 空库/空列表图标+文字层级清晰 | ☐ | ☐ |
| 7 | 外接显示器 | 不同 ColorSync profile 下颜色仍协调 | ☐ | — |
| 8 | 高对比度整体 | 高对比 dark/light 全界面可读 | ☐ | ☐ |

## 快速路径（30 秒/项）

1. dark 下打开「资料库」盯 30 秒 —— 主要看 #ABC8D4 文字与 #011F26 底色。
2. 混排 4 来源曲目，扫一眼徽标行。
3. Light 下切换「按艺人/专辑」—— 卡片间区分靠什么。
4. 侧边栏选中项 vs 曲目行选中项并排对比。
5. 导入超长文件名曲目，看列表行尾。
6. 清空资料库（或空播放列表）看空状态。
7. （仅 macOS）插外接屏，切换主副屏各看一遍。
8. 系统设置里开高对比度，全界面走一遍。
